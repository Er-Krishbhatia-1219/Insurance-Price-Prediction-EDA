# Insurance Price Prediction

Exploratory Data Analysis and Data Preprocessing project using Python to analyze factors affecting insurance charges and prepare the dataset for machine learning.

## Project Highlights

- Analyzed **1,338 records** across **7 features**
- Found **0 missing values**
- Removed **1 duplicate record**
- Performed EDA using distributions, boxplots and correlation analysis
- Encoded categorical variables
- Created BMI-based categories
- Applied feature standardization using `StandardScaler`

## Dataset

Features include:

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges

Average insurance charge: **13,270.42**

Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | Jupyter Notebook
